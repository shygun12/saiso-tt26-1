# Báo cáo công việc đo đạc – bồi thường Online V2.0

Ứng dụng Node.js + Express + PostgreSQL cho báo cáo công việc nhiều người dùng.

## Deploy Render
Repository này chứa mã V2.0. Có thể kết nối repository với Render và triển khai Web Service + PostgreSQL.

## Quy tắc
- Chỉ công việc cố định "Đã chuyển bản vẽ cho Phòng BT&GPMB" tính vào tiến độ công trình.
- Công việc khác tính vào năng suất cá nhân.
- Báo cáo đã khóa muốn sửa phải yêu cầu Admin duyệt.
- Sau khi duyệt, đúng người thực hiện sửa và lưu lại thì báo cáo khóa lại.
